# Bundled font licenses

Jump bundles variable TrueType fonts at build time; it never downloads fonts at runtime.

| Family | App resource | Authoritative source | License | SHA-256 |
|---|---|---|---|---|
| Anybody | `core/designsystem/src/main/res/font/anybody_variable.ttf` | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/anybody/Anybody%5Bwdth%2Cwght%5D.ttf) | [SIL OFL 1.1](Anybody-OFL-1.1.txt) | `b184bd7e6ca8348bbaecec98951565729d7e89b7872d4898a1f9981342b5b64c` |
| Lexend | `core/designsystem/src/main/res/font/lexend_variable.ttf` | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/lexend/Lexend%5Bwght%5D.ttf) | [SIL OFL 1.1](Lexend-OFL-1.1.txt) | `3add53e641fbc81da64da4bb254285e2831b52b029527bc0714e2b9610832ee6` |

The files are unmodified copies from the official Google Fonts repository. Anybody is used for athletic display type; Lexend is used for functional text and controls.
